Hablarle a la TV con Siri

  1. Toca Copiar en la orden que quieras.
  2. Abre la app Atajos → + → Agregar acción → busca «Obtener contenido de URL» y pega el enlace donde dice URL.
  3. Arriba, toca el nombre del atajo y escribe la frase (por ejemplo Prende la tele). Toca OK.
  4. Di «Oye Siri, prende la tele». La primera vez, iPhone pide permiso para la red local: toca Permitir.

Para que Siri te conteste, agrega también la acción «Mostrar resultado» después de la primera.
